# Bank Account Manager

A python based program the can save to and pull user bank accounts from a json file as well as add new data, display data, and delete data.

Requirements:
- Python 3.14.10
- No external libraries required

## Installation

1. Clone the repository:
   git clone https://github.com/Morbanaa/banking-app.git

2. Navigate into the project directory:
   cd AccountManager

3. Run the program:
   try: python main.py
   or: python3 main.py
